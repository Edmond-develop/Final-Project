Планировщик задач

Веб-приложение, которое помогает организовать свой день и управлять задачами быстро и удобно.

О проекте

Это современный планировщик задач на Go с фронтендом на HTML, CSS и JavaScript. С его помощью можно создавать новые задачи, редактировать их, удалять или отмечать как выполненные. Особое внимание уделено повторяющимся задачам: приложение умеет автоматически рассчитывать следующую дату выполнения, будь то каждый день, каждую неделю или раз в год.

Простота интерфейса сочетается с безопасностью: для доступа к приложению используется аутентификация по паролю, а RESTful API позволяет интегрировать сервис с другими приложениями.

Основные возможности

Создание, редактирование и удаление задач

Поддержка повторяющихся задач с гибкими интервалами

Автоматическое вычисление следующей даты для повторяющихся задач

Защищённый вход по паролю

RESTful API для внешних интеграций

Визуальное обозначение выполненных задач

✅ JWT-аутентификация для безопасной работы с API

✅ Переменные окружения для настройки порта, пароля и файла базы данных

✅ Middleware для защиты API endpoints

✅ Возможность собрать Docker-образ и запускать приложение на любом устройстве

Аутентификация

POST /api/signin — вход в систему

Работа с задачами

GET /api/tasks — получить список всех задач

GET /api/task?id=<id> — посмотреть задачу по ID

POST /api/task — создать новую задачу

PUT /api/task — обновить существующую задачу

DELETE /api/task?id=<id> — удалить задачу

POST /api/task/done?id=<id> — отметить задачу как выполненную
